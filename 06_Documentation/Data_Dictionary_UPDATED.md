# Data Dictionary

This data dictionary documents the cleaned marketing dataset and the Tableau-ready analytical fields used in the project.

## Core Dataset Fields

| Field | Description |
|---|---|
| record_id | Unique identifier for each marketing record |
| campaign_date | Date of the marketing campaign activity |
| campaign_id | Unique identifier for each campaign |
| campaign_name | Name of the marketing campaign |
| channel | Standardized marketing channel used for the campaign |
| campaign_type | Type or objective of the campaign |
| region | Standardized geographic region targeted by the campaign |
| audience_segment | Customer or audience segment targeted by the campaign |
| device | Device category used by the audience |
| impressions | Number of times the campaign was displayed |
| clicks | Number of campaign clicks |
| conversions | Number of successful conversions |
| spend_usd | Marketing spend in USD |
| revenue_usd | Revenue generated by the campaign in USD |

## Tableau-Ready Analytical Fields

| Field | Description |
|---|---|
| month_start | First day of the campaign month, used for monthly trend analysis |
| campaign_year | Calendar year extracted from campaign_date |
| campaign_month_number | Numeric month extracted from campaign_date |
| campaign_month_name | Month name extracted from campaign_date |
| year_month | Year-month label in YYYY-MM format |
| campaign_quarter | Calendar quarter derived from campaign_date |
| profit_usd | Revenue minus marketing spend |
| row_profit_margin_percentage | Row-level profit margin calculated as profit divided by revenue |

## Tableau Calculated Metrics

| Metric | Formula / Meaning |
|---|---|
| CTR | Click-through rate = SUM(clicks) / SUM(impressions) |
| Conversion Rate | SUM(conversions) / SUM(clicks) |
| CPC | Cost per click = SUM(spend_usd) / SUM(clicks) |
| Cost per Conversion | SUM(spend_usd) / SUM(conversions) |
| ROAS | Return on ad spend = SUM(revenue_usd) / SUM(spend_usd) |
| ROI | Return on investment = (SUM(revenue_usd) - SUM(spend_usd)) / SUM(spend_usd) |

## Data Quality Notes

- 6,252 raw records were assessed.
- 12 duplicate records were removed.
- The cleaned dataset contains 6,240 records.
- 14 missing audience segment values were replaced with `Unknown`.
- Marketing channel and region names were standardized before analysis.
